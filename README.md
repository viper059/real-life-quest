# Real-life Quest

รับเควสต์จริง ได้ Gold จริง เลเวลอัปจริง — ตลาดงานในชีวิตจริงที่เล่นแบบเกม RPG

- `index.html` — แอปผู้ใช้: กระดานเควสต์, ตัวละครและค่าสถานะ, การ์ดอาชีพ, กิลด์และกองทุนประกัน, เควสต์ครอบครัว, กระเป๋าเงิน
- `admin.html` — หลังบ้านสำหรับทีมงาน: ตรวจเควสต์, รายงาน, อนุมัติถอนเงิน (2 คนสำหรับยอดสูง), เคลมกองทุนกิลด์, เศรษฐกิจ, ทีมงาน, บทบาทและสิทธิ์, บันทึกการตรวจสอบ

ทั้งสองไฟล์เป็น HTML ไฟล์เดียว ไม่ต้อง build ใช้ Supabase (โปรเจกต์ `RLS`, ภูมิภาคสิงคโปร์) ผ่าน CDN

## ความปลอดภัย

คีย์ Supabase ในไฟล์เป็นคีย์ publishable ที่เปิดเผยได้ ทุกการเปลี่ยนเงิน เลเวล และสถานะ ทำผ่านฟังก์ชันในฐานข้อมูลที่ตรวจตัวตนและสิทธิ์เอง และทุกตารางเปิด Row Level Security ผู้ใช้จึงแก้ข้อมูลตรง ๆ ไม่ได้

## ตั้งค่าครั้งแรก

1. Supabase › Authentication › URL Configuration — ตั้ง Site URL เป็นที่อยู่เว็บนี้
2. สมัครผ่าน `index.html` แล้วรันใน SQL Editor ครั้งเดียว:
   ```sql
   insert into staff_members (user_id, role_id)
   select id, 'owner' from profiles where username = '<ชื่อผู้ใช้>';
   ```
3. เข้า `admin.html` ตั้งอัตรา Gold ต่อบาท โบนัสสมัคร และเพิ่มทีมงาน
