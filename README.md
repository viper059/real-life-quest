# Real-life Quest

รับเควสต์จริง ได้ Gold จริง เลเวลอัปจริง — ตลาดงานในชีวิตจริงที่เล่นแบบเกม RPG

- `index.html` + `app.css` + `js/` — แอปผู้ใช้
  - `js/core.js` เชื่อม Supabase, สถานะ, เข้าสู่ระบบ, แจ้งเตือน, Web Push, พร้อมเพย์ QR, อัปโหลดไฟล์
  - `js/quests.js` กระดาน, แผนที่เรดาร์ (OpenStreetMap), โพสต์งานพร้อมหมุด Google Maps, สมัคร/เลือกผู้รับงาน, เช็กอิน-เช็กเอาต์, ส่งงาน, ยืนยัน, รีวิว, ข้อพิพาท, แชต
  - `js/me.js` ตัวละคร, ค่าสถานะ, อุปกรณ์, ยืนยันตัวตน, อาชีพและขั้น, เทียบโอน, คำรับรอง, เด็คการ์ด
  - `js/social.js` กิลด์และกองทุน, ครอบครัว (มอบเควสต์, รับรองเป้าหมายลูก, ส่ง Crystal)
  - `js/wallet.js` Gold, Crystal, เติมด้วยพร้อมเพย์ + สลิป, ส่ง Crystal, ร้านค้า
  - `js/planner.js` ภารกิจรายวัน + หีบต่อเนื่อง, ประจำเดือน + รางวัลสะสม, เป้าหมายส่วนตัว
- `admin.html` — หลังบ้าน: ตรวจเควสต์, รายงาน, ยืนยันตัวตน, ข้อพิพาท, ผู้ใช้และการแบน, เลื่อนขั้นอาชีพ, ยืนยันเติมเงิน, ร้านค้า, กิลด์, ตั้งค่าเศรษฐกิจ, ทีมงาน, สิทธิ์, บันทึกการตรวจสอบ
- `terms.html`, `privacy.html` — ฉบับร่าง รอทนายตรวจ
- `supabase/migrations/` — SQL ทั้งหมด (0001–0007) · `supabase/tests/` — ทดสอบฐานข้อมูลแบบออฟไลน์ด้วย PGlite · `supabase/functions/send-push/` — ส่ง Web Push

ไม่ต้อง build ใช้ CDN ทั้งหมด

## ระบบเงิน

- **ค่าจ้างงาน = เงินบาทจริง** ผู้จ้างจ่ายให้ผู้รับงานโดยตรง (QR พร้อมเพย์ของผู้รับงานที่แอปสร้างให้ หรือเงินสด) แอปไม่รับหรือถือเงินค่าจ้าง ผู้รับงานกด "ได้รับเงินแล้ว" · ผู้จ้างที่ถูกแจ้งว่าไม่จ่ายโพสต์งานใหม่ไม่ได้จนทีมงานปิดเรื่อง
- **Gold** เงินในแอป (คล้าย Robux) ขายเป็นจำนวนมาก ใช้ลงประกาศงาน (`post_fee_gold`, `urgent_fee_gold`) ซื้อของ และมอบเควสต์ในครอบครัว
- **Crystal** สกุลพิเศษสำหรับของรุ่นจำกัด (`shop_items.stock`) ส่งให้คนอื่นได้
- ถอนไม่ได้ทั้งคู่ · รายได้แพลตฟอร์ม = ขาย Gold + ขาย Crystal + ค่าลงประกาศ
- **แลกเครดิตจากแอปอื่น** (ปักหมุด/feedTH, ส่งด่วน, …) เป็น Gold ได้ทางเดียว ผ่าน edge function `exchange` ดู [docs/exchange-api.md](docs/exchange-api.md)

## ระดับไอเทม (ของใช้และของแต่งตัว)

ธรรมดา → ไม่ธรรมดา → อีปิก → รีเจน → มิสติก → ซูเปอร์มิสติก → ดีวาย → สวรรค์

ตอนนี้ผู้ใช้หาได้สูงสุดอีปิก ระดับรีเจนขึ้นไปยังปิด (`rarity_tiers.obtainable = false`) ขายหรือแจกไม่ได้ การ์ดอาชีพไม่มีระดับ

## กิจวัตรประจำวัน

ดื่มน้ำ +2 (8 ครั้ง/วัน ห่าง 45 นาที) · แปรงฟัน +3 (2 ครั้ง ห่าง 6 ชม.) · ข้าวเช้า/กลางวัน/เย็น +5 (มื้อละครั้งในช่วงเวลา) · นักเรียน: ไปโรงเรียน +10, กลับบ้าน +5, การบ้าน +10 (ผู้ปกครองรับรอง) · คนทำงาน: ไปทำงาน +10, วางแผนงาน +3, ปิดงาน +5, ยืดเส้น +1, จดรายรับรายจ่าย +3, กลับบ้าน +5 · เลือกได้บทบาทเดียว เปลี่ยนได้ทุก 30 วัน — รวมกันไม่เกิน `habit_exp_cap` (60) ต่อวัน แก้รายการได้ในตาราง `habit_templates`

## ความปลอดภัย

คีย์ Supabase ในไฟล์เป็นคีย์ publishable ที่เปิดเผยได้ ทุกการเปลี่ยนเงิน เลเวล ขั้นอาชีพ และสถานะ ทำผ่านฟังก์ชันในฐานข้อมูลที่ตรวจตัวตนและสิทธิ์เอง ทุกตารางเปิด Row Level Security

## ตั้งค่าครั้งแรก

1. รัน migration 0001–0007 ตามลำดับ (หรือให้ Claude ทำผ่าน Supabase connector)
2. Supabase › Authentication › URL Configuration — ตั้ง Site URL เป็นที่อยู่เว็บนี้
3. สมัครผ่าน `index.html` แล้วรันใน SQL Editor ครั้งเดียว:
   ```sql
   insert into staff_members (user_id, role_id)
   select id, 'owner' from profiles where username = '<ชื่อผู้ใช้>';
   ```
4. เข้า `admin.html` › ตั้งค่าเศรษฐกิจ: `gold_thb_rate`, `crystal_thb_rate`, `promptpay_id`, `promptpay_name` (เติมเงินเปิดเมื่อครบ)
5. Web Push: ตั้ง secrets ของ edge function `send-push` = `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `PUSH_SECRET` (ค่าเดียวกับ `select value from private.secrets where key = 'push_secret'`) แล้ว deploy
